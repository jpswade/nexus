# Map outlines

`land.json` contains simplified exterior land rings derived from Natural Earth 1:110m land polygons. Coordinates are longitude/latitude in degrees. Simplification retains vertices roughly two degrees apart for a lightweight display; this is a decorative overview, not a navigation map.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/
